# OmniMind Web Access provider icons

These files are the production-admitted provider marks for OmniMind Web Access.
They are copied byte-for-byte from `@lobehub/icons-static-svg@1.94.0`, which is
locked by `bun.lock` and distributed under the MIT license. Marks remain the
property of their respective owners and are used only to identify the provider
selected by the user.

The runtime provider descriptor is the admission owner. A file in this directory
is not reachable unless that descriptor projects it as `local-asset`. Providers
without a closed admission continue to use the neutral provider mark.
