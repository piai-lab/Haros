# Freeze the authoritative Product-truth v5 meter

## Objective

Replace rejected immutable v4 measurement authority with one narrow v5 meter. V5 preserves v4's
accepted frozen universe, capability roots, path-origin authority, semantic counters and complete
fixture matrix, while closing the failed Review's five counterexamples with a production+direct-tool
capability domain, per-acquisition same-predecessor lock must-analysis and reachability-based refusal
CFG/ICFG. This Work implements measurement only.

V1-v4 code, config, tests, fixtures, reports, handoffs and Reviews remain immutable rejected
evidence. The five Work fences, Product code, direct-rebuild behavior, dependency manifests/locks,
architecture owners, Campaign state and user state are outside this Work.

## Done conditions

- Re-extract and pin the inherited five Work blocks, capability and owner-lock blocks, frozen
  membership, dependency forms and complete derived inventory exactly as v4 required. Run
  candidate capability discovery over every materialized `production` **and** `direct-tool` member;
  exclude direct-tool only from ordinary-runtime owner-lock proof.
- Implement one bounded explicit CFG/ICFG used by both refusal and lock analysis. Each acquisition
  creates a unique abstract token; actual predecessor meet preserves held only for the same binding
  and same token. Alias release, branch phi, loop, call/return, catch/finally and resource-scope edges
  update state; detached/unresolved scheduling is release-capable unknown and fails closed.
- Interpret present/absent polarity and actual reachability. Model zero-iteration `for`/`for...of`/
  `while`, one-or-more `do`, exact constant branches, abrupt completion and catch/finally. The exact
  typed throw must cut every legacy-present successor; swallowed or unreachable throws do not count.
  Unsupported proof-relevant flow fails closed.
- Preserve all v4 metrics and inherited fixtures. Add the exact direct-tool SQLite/DELETE, different-
  handle branch phi, detached microtask release, empty-iterable `for...of` guard and false conditional
  rethrow negatives. Preserve reversed-null, negated-exists and all H1-H10/matrix tests.
- Freeze one clean dedicated commit containing only allowed v5 code paths. Record full SHA, accepted
  Design SHA, all authority/inventory/universe digests, byte-deterministic B0, per-owner CFG/lock
  witnesses, focused results, typecheck and v1-v4 immutability in the handoff.

## Verification

- Run focused authority, membership, dependency, candidate capability, path/handle provenance,
  presence-polarity, reachability and lock-token tests. Each negative must fail for its intended
  single cause and include a bounded witness.
- Run v5 twice against immutable B0 and require byte-identical complete JSON.
- Compare all v1-v4 bytes for immutability; none can satisfy a current gate.
- Run scripts typecheck and `git diff --check`; prove no runtime, dependency, direct-tool behavior,
  Work fence or user-state path changed and no real `~/.omnimind` was read.
