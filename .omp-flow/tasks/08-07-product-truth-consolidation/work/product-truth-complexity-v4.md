# Freeze the authoritative Product-truth v4 meter

## Objective

Replace rejected immutable v3 measurement authority with a new immutable v4 meter before any
repaired B1 production work. V4 preserves the accepted frozen-universe and candidate-graph model,
but discovers the complete resolved database opener/wrapper/caller/handle graph before Product
classification and proves the Product/service two-stage and Web single-stage refusal cuts over
every reachable current-generation I/O sink. This Work implements measurement only.

## Done conditions

- Config extraction, Design pinning, normalized five-Work blocks/digests, one-time glob expansion,
  frozen membership, dependency integrity and candidate-time graph rules satisfy the v4 interface.
- The meter enumerates every resolved database opener/constructor invocation before Product
  classification; closed interprocedural path and handle summaries cover wrappers, callers,
  aliases, returns, receivers and branch merges. Generic wrapper summaries are instantiated per
  resolved caller context; unresolved persistent database flow fails. No text/Product-name
  prefilter participates.
- Every Product component is inside frozen membership and has canonical-resolver-only provenance.
  Generic wrapper plus raw Product path, constructor alias and mixed caller/handle provenance fail.
- For exact Product and service owner entries, complete main/WAL/SHM pre-mutation cuts dominate
  current stores mkdir/file/lock and complete post-lock cuts dominate every subsequent
  read/create/open/write/receiver sink. The Web v1/v2 cut dominates all g1 sinks. Present legacy
  cannot reach current I/O on any reachable path.
- The complete inherited and new v4 adversarial matrix passes/fails for its intended single cause.
  The two Review counterexamples, a missing sidecar, preguard without postguard, branch/catch/
  finally/deferred bypass and a raw Product path behind neutral names all fail. Unsupported
  callback/Effect/recursion/control edges fail closed.
- One clean dedicated commit contains only allowed v4 paths. The handoff records its full SHA,
  accepted Design SHA, script/config/boundary/universe digests and byte-deterministic B0 report.
  Exact B0 reports historical semantic red without weakening authority/integrity failures; every
  other candidate and focused semantic fixture enforces the same findings as hard failures.
