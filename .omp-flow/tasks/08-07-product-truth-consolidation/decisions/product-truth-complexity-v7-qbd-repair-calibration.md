# Product-truth complexity v7 QbD repair calibration

## Human calibration applied

Main accepts the independent [v7 authority audit](../qbd/product-truth-complexity-v7-audit.md) as
`FAIL` under the maintainer's standing instruction to continue the narrow high-quality repair. The
selected option keeps the v7 Occam split and closes both blockers with Design-owned machine
authority; it does not restore a JavaScript semantic interpreter.

First, v7 must freeze an exhaustive raw-effect ingress vocabulary and dependency-effect inventory.
It must cover the supported Node, Bun, Deno, Electron, browser/OPFS, LevelDB, SQLite, process,
worker, dynamic-loader, native-addon and shell forms, including synchronous variants and indirect
ambient loaders. Unknown package exports or dependencies that can construct, return or execute a
raw effect must fail authority derivation rather than rely on prose such as “equivalent”.

Second, B1 must freeze a per-owner verification universe before implementation: exact injected port
operations, operation atomicity, port-to-event mapping, before/after fault sites, race barriers,
durable-kill boundaries, required observable outcomes and excluded bytes/paths. Candidate code may
implement those ports but may not add, merge, omit or redefine the verification universe or expected
trace. Static ingress closure and the frozen behavior harness remain conjunctive and cannot
substitute for each other.

This decision authorizes only the corresponding v7 PRD/Design/interface/Work-map repair followed by
a fresh different-actor QbD. It authorizes no meter implementation, B1 production work, destructive
execution, dependency change, Campaign promotion or read/mutation of real `~/.omnimind`.
