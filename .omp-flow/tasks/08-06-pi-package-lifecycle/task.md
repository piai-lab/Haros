# Deliver the Pi Package lifecycle

Task directory: `08-06-pi-package-lifecycle`.

## Purpose and authority

Deliver the sole next stage named by [`execution-brief.md` §9](../../../execution-brief.md): one
exact, mature, headless Pi Package running through Pi-native `ResourceLoader` and lifecycle in the
isolated Native Host. Product-owned source, rights, trust, staged activation, current/LKG generation
and active lease remain distinct from Pi/Package-owned loading, execution semantics and private
state.

Product and architecture meaning remain owned by [`README.md`](../../../README.md),
[`architecture/workbench.md`](../../../architecture/workbench.md),
[`architecture/product-state.md`](../../../architecture/product-state.md) and
[`architecture/execution.md`](../../../architecture/execution.md). Campaign status remains solely in
[`missions/independent-omnimind-v1.md`](../../../missions/independent-omnimind-v1.md). Exact Pi/source
and legal evidence routes through [`research/source-review.md`](../../../research/source-review.md)
and the accepted 08-04 evidence; this Bundle does not duplicate those owners.

## Scope

- adopt one exact Package artifact only after its source, rights and compatibility are reviewable;
- stage before activation, preserve current/LKG on failure and never hot-replace an active lease;
- execute Package code only in the isolated Native Host through Pi-native lifecycle;
- prove normal activation/use, rejection, crash/fault, restart/recovery, lease stability and LKG
  rollback with typed Product facts and no secret leakage;
- produce a bounded handoff, different-actor review and atomic Package checkpoint commit;
- submit only affected Campaign claims to at most `candidate`.

## Non-goals and stop conditions

Do not reopen product Converge/QbD, redesign the UI chassis, create a second Runtime/Session/Queue/
Todo/Workflow/Package loader, advertise process isolation as sandbox, or begin External Engine,
Remote, Marketplace expansion, Windows/Linux, signing or release publication. Stop if exact rights
cannot support the selected artifact, Product and Pi both own the same lifecycle fact, Package code
enters Electron Main/renderer/Product Service, active generations hot-replace, failure can destroy
the LKG, or evidence would require blind replay or credential disclosure.

The two uncommitted Package documents under the completed 08-04 Bundle are recoverable drafting
inputs only. After the canonical Executor receives `START`, it may migrate or rebuild their useful
content here with current evidence; they must not be committed as an extension of 08-04.
