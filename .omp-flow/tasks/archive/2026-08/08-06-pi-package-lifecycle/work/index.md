# Deliver the Pi Package lifecycle

## Authorized execution view

This Bundle has one implementation Work only:

- [Run one trusted headless Pi Package](run-trusted-headless-pi-package.md) freezes one exact,
  rights-cleared and compatible Package artifact, then implements Product-owned governance around
  Pi-native loading, lifecycle and private state in the existing isolated Native Host.

The Work begins with an evidence gate. A candidate Package is not selected until its exact bytes,
source revision and path, publisher and MIT rights chain, Pi `0.81.1` compatibility, headless
surface and representative maturity are independently reproducible. A failed candidate narrows or
blocks this Work; it does not authorize a replacement architecture or a second Package loader.

Implementation follows only after that gate: immutable stage, ResourceLoader validation, activation
with current/LKG facts, active-generation lease admission, native execution/private-state proof,
fault quarantine and recovery. The linked handoff records producer evidence; a different actor owns
the final normal/failure/recovery/fault review and is the only actor that may record `PASS`.

## Completion boundary

Completion requires one reviewed immutable candidate, not OmniMind V1 completion. Affected Campaign
claims may advance only to `candidate`; External Engine, Remote, Marketplace, cross-platform,
signing/publication, Package UI and arbitrary install/update remain outside this Bundle.
