# Preserve OmniMind architecture and UI contract

Task directory: `08-03-architecture-ui-contract`.

The durable outcome is a repository that a fresh Agent can understand without chat history:

- product doctrine remains concise at the root;
- accepted architecture and the complete UI contract have stable topical homes;
- fixed-source facts and superseded decisions remain auditable but non-normative;
- execution and Campaign documents point to the same current route;
- no documentation change silently alters Runtime, Package implementation or process topology.

Authoritative product outputs live outside this Bundle in [`architecture/`](../../../architecture/README.md) and [`research/`](../../../research/README.md). This Bundle owns only the task framing, evidence, design, audits and handoffs.
