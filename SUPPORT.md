# Haros Support

Haros is currently a source alpha. There are no official installers, releases, or paid support
channels yet.

- Use [GitHub Discussions](https://github.com/piai-lab/Haros/discussions) for setup help, usage
  questions, and broader ideas.
- Use [GitHub Issues](https://github.com/piai-lab/Haros/issues) for reproducible bugs and focused
  feature requests.
- Follow [SECURITY.md](SECURITY.md) for vulnerability reports. Do not disclose vulnerabilities in
  a public issue or discussion.

When reporting a bug, include the exact commit or version, operating system, reproduction steps,
expected behavior, and sanitized logs. Never include credentials, private endpoints, or user data.
