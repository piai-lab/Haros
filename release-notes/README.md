# Release Notes

This directory is the reviewed public content owner for OmniMind Desktop releases.

Publication requires `release-notes/<tag>.md`, for example `release-notes/v1.0.0.md`. Each file must contain exact `## English` and `## 中文` sections. The release workflow publishes that same file to the public `SolvingLab/OmniMind-Releases` authority; the existing website `/changelog` surface reads the resulting public release record.

Do not include private repository links, internal issue identifiers, credentials, provider-private state, user data, or unannounced capabilities. A note does not activate a release by itself: signing, provenance, legal metadata, artifact checks, and updater proof remain mandatory gates.
