# Repository Provenance

The independent HarnessOS repository was split from the former OmniMind repository's
`omnimind-alpha` branch at exact commit `f310080bfa1df72eade006d3d74143892c05f9b4`. All history
reachable from that commit is retained. Subsequent HarnessOS work is independent and has no shared
package, submodule, build dependency, or automatic synchronization with the former repository.

The annotated `harnessos-fork-base` tag identifies that exact boundary. Adopted external source and
redistribution facts are recorded separately in [`source-adoptions.json`](../source-adoptions.json).
